### 224. 基本计算器

题意

计算仅含 `+ -`、括号和空格的表达式。

解题思路

先去除空格，再逐个扫描，能算则算，算的条件比较特殊`!op.isEmpty() && op.peek() != '('`

```java
class Solution {
    void doCal(Deque<Character> op, Deque<Integer> num) {
        char c = op.pop();
        int b = num.pop(), a = num.pop();
        if (c == '+') num.push(a + b);
        else num.push(a - b);
    }
    public int calculate(String s) {
        int n = s.length();
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) != ' ') sb.append(s.charAt(i)); // 先去除空格 
        }
        s = sb.toString();
        n = s.length();

        Deque<Character> op = new ArrayDeque<>(); // 符号栈
        Deque<Integer> num = new ArrayDeque<>(); // 操作数栈

        for (int i = 0; i < n; i++) {
            char c = s.charAt(i);
            if (c == '+' || c == '-') {
                if (i == 0 || s.charAt(i - 1) == '(') num.push(0); // -x 和 (-x) 的情况向数字栈添加一个0
                op.push(c);
            } else if (c == ')') {
                op.pop(); // 弹出'('
                if (!op.isEmpty() && op.peek() != '(') doCal(op, num);
            } else if (c == '(') op.push(c);
            else { // 处理数字
                int j = i;
                while (j < n && Character.isDigit(s.charAt(j))) j++;
                num.push(Integer.valueOf(s.substring(i, j)));
                i = j - 1;
                if (!op.isEmpty() && op.peek() != '(') doCal(op, num);
            }
        }
        return num.pop();
    }
}
```

### 补充题1. 排序奇升偶降链表

题意

链表奇数位升序、偶数位降序，要求整体按升序重排。

解题思路

拆分奇位链表（升序）与偶位链表（降序），将偶位链表反转成升序，再按归并两个有序链表合并。

```java
import java.util.*;

public class OddEvenSort {
    static class Node {
        int val;
        Node next;
        Node() {}
        Node(int val, Node next) { this.val = val; this.next = next; }
    }

    static void partition(Node root, Node odd, Node even) {
        if (root == null) return;
        Node p = odd, q = even, cur = root;
        int cnt = 1;
        while (cur != null) {
            if (cnt % 2 == 1) { p.next = cur; p = p.next; }
            else { q.next = cur; q = q.next; }
            cur = cur.next;
            cnt++;
        }
        p.next = null;
        q.next = null;
    }

    static Node reverseList(Node root) {
        Node p = null, q = root, r = null;
        while (q != null) {
            r = q.next;

            q.next = p;
            p = q;
            q = r;
        }
        return p;
    }

    static Node mergeList(Node list1, Node list2) {
        Node dummy = new Node();
        Node p = list1, q = list2;
        Node cur = dummy;
        while (p != null && q != null) {
            if (p.val <= q.val) { cur.next = p; p = p.next; }
            else { cur.next = q; q = q.next; }
            cur = cur.next;
        }
        while (p != null) { cur.next = p; p = p.next; cur = cur.next; }
        while (q != null) { cur.next = q; q = q.next; cur = cur.next; }
        return dummy.next;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        Node dummy = new Node();
        Node cur = dummy;
        int n = sc.nextInt(); // 节点个数
        while (n-- > 0) {
            cur.next = new Node(sc.nextInt(), null);
            cur = cur.next;
        }

        Node odd = new Node(), even = new Node();
        partition(dummy.next, odd, even);
        even.next = reverseList(even.next);
        dummy.next = mergeList(odd.next, even.next);

        cur = dummy.next;
        while (cur != null) { System.out.print(cur.val + " "); cur = cur.next; }
    }
}
```

### 440. 字典序的第K小数字

题意

在区间 `[1, n]` 的所有数字按字典序排序，求第 k 小数字。

解题思路

**字典树式计数：**从前缀 `curr=1` 开始，计算从 `curr` 到 `curr+1` 之间在 `[1,n]` 的步数 `step-s`；若 `steps<=k-1`，则 `k-=steps`，`curr++`（同层右移）；否则 `k--`，`curr*=10`（下探到子前缀）。直到 `k==1` 返回 `curr`。

```java
class Solution {
    // 确定以prefix为前缀的1~n的数量
    int f(int prefix, int n) {
        int res = 0, p = 1; // p表示根据当前位数的前缀树
        String a = String.valueOf(prefix), b = String.valueOf(n);
        // 先统计前缀位数比n小的数量
        for (int i = 0; i < b.length() - a.length(); i++) {
            res += p;
            p *= 10;
        }
        // 再统计前缀位数和n相同时的情况，取n的前prefix位比较即可
        String c = b.substring(0, a.length());
        if (a.compareTo(c) < 0) res += p;
        else if (a.equals(c)) res += n - prefix * p + 1;
        return res;
    }
    public int findKthNumber(int n, int k) {
        int prefix = 1;
        while (k > 1) { // 逐位确定
            int cnt = f(prefix, n);
            if (k > cnt) {
                prefix++;
                k -= cnt;
            } else {
                k--;
                prefix *= 10;
            }
        }
        return prefix;
    }
}
```

### 45. 跳跃游戏 II

题意

到达数组末尾的最少跳跃次数（每步可在范围内任意跳）。

解题思路

贪心分层：维护当前层能到的最远 `end` 与下一层最远 `far`，遍历到 `end` 时步数+1并更新 `end=far`，直至覆盖末尾。

```java
class Solution {
    public int jump(int[] nums) {
        int n = nums.length;
        // lim本轮最远能到达的地方，ne下轮最远能到的地方，cnt跳跃次数
        // 初始站在位置0
        int lim = 0, ne = 0, cnt = 0;
        for (int i = 0; i < n - 1; i++) { // 站在 n - 2 跳一次一定能跳到终点，而且这次跳跃已经计数了
            ne = Math.max(ne, i + nums[i]);
            if (i == lim) { // 到达本轮最远距离，得跳一次
                lim = ne;
                cnt++;
            }
        }
        return cnt;
    }
}
```

### 补充题2. 圆环回原点问题

题意

    int[][] f = new int[n + 1][10]; // f[i][j]表示走i步，到达位置j的方案数
    f[0][0] = 1;
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j < 10; j++) {
            f[i][j] = f[i - 1][(j + 1) % 10] + f[i - 1][((j - 1) % 10 + 10) % 10];
        }
    }
    return f[n][0];
}
```

            if (c == '(') { low++; high++; }
            else if (c == ')') { low--; high--; }

题意

class Solution {
    public int findNthDigit(int n) {
        long bit = 1, cnt = 9, start = 1; // bit位数，共有cnt个，从start开始
        // 确定位数
        while (n > cnt * bit) {
            n -= cnt * bit;
            bit++;
            cnt *= 10;
            start *= 10;
        }
        // 确定在哪个数上，比如n = 5，bit = 3，start = 100，应该在第2个数上
        // 也就是n/bit上取整个数上，也就是(n + bit - 1) / bit
        long x = start + (n + bit - 1) / bit - 1;
        // 确定n在x的第几位
        // 比如n = 6，在第三位，比如 n = 5，在第二位
        n = (int)(n % bit == 0 ? bit : n % bit);
        return String.valueOf(x).charAt(n - 1) - '0';
    }
}
```

题意

解题思路

单调栈 + 贪心

```java
class Solution {
    public String removeDuplicateLetters(String s) {
        StringBuilder res = new StringBuilder();
        Map<Character, Boolean> hash = new HashMap<>(); // 当前字母是否在答案中出现
        int[] last = new int[26]; // 每个字母最后一次出现的位置
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
        }

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if(hash.getOrDefault(c, false)) continue;
            // last[res.charAt(res.length() - 1) - 'a'] != i是不对的，比如cba，扫描到a，会把cb都弹出！
            while (res.length() > 0 && last[res.charAt(res.length() - 1) - 'a'] > i && res.charAt(res.length() - 1) > c) {
                hash.put(res.charAt(res.length() - 1), false);
                res.delete(res.length() - 1, res.length());
            }
            hash.put(c, true);
            res.append(c);
        }
        return new String(res);
    }
}
```

### 416. 分割等和子集

题意

判断能否将数组分成两个子集，使和相等。

解题思路

转换为 0/1 背包：目标容量 `target=sum/2`（若 sum 为奇数直接 false）；一维 DP 从大到小遍历 `for v from target..num: dp[v]|=dp[v-num]`，初始 `dp[0]=true`，看 `dp[target]`。
