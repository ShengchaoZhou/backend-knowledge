# 设计模式

## 单例模式

### 双重检查锁

```java
public class Singleton {
    private static volatile Singleton obj;

    private Singleton(){}

    public static Singleton getObj() {
        if (obj == null) {
            synchronized (Singleton.class) {
                if (obj == null) {
                    obj = new Singleton();
                }
            }
        }
        return obj;
    }
}
```

1. **为什么要做“两次检查”而不是进入同步块再检查一次就返回？**

- **第一次检查**：大部分并发场景下，实例已经创建完成；先检查可以**绕过同步**，避免每次都竞争锁，降低开销。
- **第二次检查**：保障安全。当多个线程几乎同时通过第一次 `obj == null` 时，只有**第一个线程**进入同步块能真正创建实例，其余线程第二次检查会发现实例已存在，避免重复创建。比如另一个线程原来是被synchronized锁阻塞的，现在获得锁后如果不检查就会再去新建对象。

2. **如果把 `volatile` 去掉，代码还安全吗？**

   不安全。去掉 `volatile` 会留下**指令重排**隐患：

   线程 A 执行 `obj = new Singleton()` 可能被重排为：

   - (1) 分配内存
   - (2) **将引用赋给 `obj`**
   - (3) 调用构造方法初始化

   线程 B 第一次检查发现 `obj!=null`，直接拿到一个“**半初始化**”实例，接着访问字段可能触发 NPE 或读到脏数据。
   `volatile` 禁止 (2)-(3) 的重排，并提供写–读可见性。

### 静态内部类

```java
public class Singleton2 {
    private Singleton2() {};

    public static Singleton2 getObj() {
        return SingletonInner.obj;
    }

    private static class SingletonInner {
        private static final Singleton2 obj = new Singleton2();
    }
}
```

1. **类加载懒惰性 (Lazy Class Loading)**
   - 只有在第一次主动使用 `SingletonInner`（即读取其静态字段 `obj`）时，类加载器才会按需加载并初始化该内部类。
2. **JVM 对类初始化的同步保证**
   - **《Java Language Specification §5.5》**：类或接口的初始化过程在多线程环境下由 JVM 隐式加锁，同一时刻只有一个线程能执行 `<clinit>` 方法，其余线程会在 `Class` 对象的 **初始化锁** 上等待。
   - 初始化完成以后，所有线程都能看到 `obj` 的正确构造结果（满足 happens-before 原则）。

> 这套机制被称为 **“Initialization-on-Demand Holder Idiom”**，本质上是**利用 JVM 类加载 & 初始化时机** 来同时获得「延迟实例化」与「线程安全」两个特性，而不依赖语言层显式同步。

# 多线程问题

## ReentrantLock模板

```java
public class Main {
    static ReentrantLock lock = new ReentrantLock();
    static Condition c = new lock.newCondition(); // 条件变量必须要和锁绑定
    static int state = 0;

    static private void print(int u, String s) {
        // 先加锁
        lock.lock();
        try {
            // 临界区
            c.await(); state++; c.signal();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        } finally {
            lock.unlock();
        }
    }

    public static void main(String[] args) {
        new Thread(()-> print(0, "A")).start();
    }
}
```

## 循环打印ABC

```java
package solutions.others;

import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.ReentrantLock;

public class PrintABC {
    static ReentrantLock lock = new ReentrantLock();
    static Condition[] c = { lock.newCondition(), lock.newCondition(), lock.newCondition() };
    static int rounds = 10;
    static int turn;

    static private void print(int u, String s) {
        for (int i = 0; i < rounds; i++) {
            lock.lock();
            try {
                while (turn != u) c[u].await();
                System.out.print(s + " ");
                turn = (turn + 1) % 3;
                c[turn].signal();
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            } finally {
                lock.unlock();
            }
        }
    }

    public static void main(String[] args) {
        new Thread(()-> print(0, "A")).start();
        new Thread(()-> print(1, "B")).start();
        new Thread(()-> print(2, "C")).start();
    }
}
```



## 多线程插入/删除

1. 如果是生产者-消费者并且需要背压(ruguo)，就用阻塞队列（`LinkedBlockingQueue/ArrayBlockingQueue`）。简易实现：参考ArrayBlockingQueue，环形数组，泛型，ReentrantLock，两个Condition。

```java
import java.util.concurrent.TimeUnit;
import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.ReentrantLock;

public class BoundedBlockingQueue<E> {
    private final Object[] items;
    private int head = 0, tail = 0, size = 0;   // 环形队列指针与元素个数
    private final ReentrantLock lock = new ReentrantLock(); // 可选公平: new ReentrantLock(true)
    private final Condition notEmpty = lock.newCondition();
    private final Condition notFull  = lock.newCondition();

    public BoundedBlockingQueue(int capacity) {
        if (capacity <= 0) throw new IllegalArgumentException();
        this.items = new Object[capacity];
    }

    // 阻塞放入（背压）
    public void put(E e) throws InterruptedException {
        if (e == null) throw new NullPointerException();
        lock.lockInterruptibly();
        try {
            while (size == items.length) notFull.await(); // 满则等待
            items[tail] = e;
            tail = (tail + 1) % items.length;
            size++;
            notEmpty.signal(); // 唤醒一个消费者
        } finally {
            lock.unlock();
        }
    }

    // 阻塞取出
    @SuppressWarnings("unchecked")
    public E take() throws InterruptedException {
        lock.lockInterruptibly();
        try {
            while (size == 0) notEmpty.await(); // 空则等待
            Object x = items[head];
            items[head] = null;                 // help GC
            head = (head + 1) % items.length;
            size--;
            notFull.signal();  // 唤醒一个生产者
            return (E) x;
        } finally {
            lock.unlock();
        }
    }

    // 可选：带超时的 offer/poll，面试加分
    public boolean offer(E e, long timeout, TimeUnit unit) throws InterruptedException {
        if (e == null) throw new NullPointerException();
        long nanos = unit.toNanos(timeout);
        lock.lockInterruptibly();
        try {
            while (size == items.length) {
                if (nanos <= 0L) return false;
                nanos = notFull.awaitNanos(nanos);
            }
            items[tail] = e;
            tail = (tail + 1) % items.length;
            size++;
            notEmpty.signal();
            return true;
        } finally {
            lock.unlock();
        }
    }

    @SuppressWarnings("unchecked")
    public E poll(long timeout, TimeUnit unit) throws InterruptedException {
        long nanos = unit.toNanos(timeout);
        lock.lockInterruptibly();
        try {
            while (size == 0) {
                if (nanos <= 0L) return null;
                nanos = notEmpty.awaitNanos(nanos);
            }
            Object x = items[head];
            items[head] = null;
            head = (head + 1) % items.length;
            size--;
            notFull.signal();
            return (E) x;
        } finally {
            lock.unlock();
        }
    }

    public int size() {
        lock.lock();
        try { return size; }
        finally { lock.unlock(); }
    }
}
```

2. 如果不需要阻塞、要低延迟，用无锁队列 `ConcurrentLinkedQueue`（Michael–Scott，CAS）。CAS的具体实现使用AtomicReference的compareAndSet()。

```java
import java.util.concurrent.atomic.AtomicReference;

public class MSQueue<E> {
    // 单向链表节点
    private static final class Node<E> {
        volatile E value;
        final AtomicReference<Node<E>> next = new AtomicReference<>(null);
        Node(E value) { this.value = value; }
    }

    // 头、尾指针（都可能被多线程修改）
    private final AtomicReference<Node<E>> head;
    private final AtomicReference<Node<E>> tail;

    public MSQueue() {
        Node<E> dummy = new Node<>(null); // 哨兵
        head = new AtomicReference<>(dummy);
        tail = new AtomicReference<>(dummy);
    }

    // 非阻塞入队：O(1) 摆动，锁自由（lock-free）
    public void offer(E e) {
        if (e == null) throw new NullPointerException();
        Node<E> node = new Node<>(e);
        while (true) {
            Node<E> t = tail.get();
            Node<E> next = t.next.get();
            if (t == tail.get()) {                    // 读到一致的快照
                if (next == null) {                   // t 确实是最后一个
                    if (t.next.compareAndSet(null, node)) { // 把新节点挂到末尾
                        // 尝试推进 tail（失败也无所谓，别的线程会帮忙）
                        tail.compareAndSet(t, node);
                        return;
                    }
                } else {
                    // tail 落后了，顺手推进
                    tail.compareAndSet(t, next);
                }
            }
        }
    }

    // 非阻塞出队：空则返回 null
    public E poll() {
        while (true) {
            Node<E> h = head.get();
            Node<E> t = tail.get();
            Node<E> next = h.next.get(); // 真实的队头元素在 h 的后一个
            if (h == head.get()) {       // 读到一致的快照
                if (next == null) {      // 空队列（只有哨兵）
                    return null;
                }
                if (h == t) {
                    // tail 也落后了，帮它推进
                    tail.compareAndSet(t, next);
                } else {
                    E val = next.value;
                    // 把 head 前移到 next，弹出元素
                    if (head.compareAndSet(h, next)) {
                        next.value = null; // help GC（可选）
                        return val;
                    }
                }
            }
        }
    }

    // 仅供方便：是否为空（近似 O(1) 观察）
    public boolean isEmpty() {
        return head.get().next.get() == null;
    }
}
```

# 非常规代码题

## 不大于n的最大的数

题目描述：

给定一个数组A,利用A中的数字组合形成小于n的最大数，且A中的数字可以重复使用 例如 ：

1. A = [6,8] n = 100 那么得到的数字是88
2. n = 23121; A = {2,4,9}求由A中元素组成的、小于n的最大数,如小于23121的最大数为22999

思路：

- `digits`：给定可用数字集合（可重复使用）。
- 首先尝试构造与 `n` 同长度的数：
  - 第 `i` 位的上限是 `n[i]`（若前缀完全相等），否则是 `9`。
  - 选取**不超过上限的最大允许数字**（首位不能为 0，除非 `n` 本身一位）。
  - 若该位没有可选数，则**回退**到前一位，把前一位降到它可用的次大值，再把后面位全部填“允许的最大数字”。
  - 若最终得到的数恰好等于 `n`，再做一次“从后往前”的回退，使它严格小于 `n`。
- 如果同长度无解，改用**更短长度**：首位选最大非 0 允许数字，其余位全填最大允许数字（都不存在时继续缩短）。
- 特殊：若只有 `0` 可用，且 `n>0`，答案是 `0`；若 `n==0` 则无解。

```java
import java.util.*;

public class MaxLessThanN {
    // 传入: digits 为可用数字集合(0~9)，n 为上界
    // 返回: 小于 n 的最大“非负整数”（允许返回 "0"）；若不存在则返回 "-1"
    public static String maxNumBelowN(int[] digits, int n) {
        if (n <= 0) return "-1"; // 只能构造非负数，若 n<=0 不存在解

        // 可用数字集合（去重并排序）
        TreeSet<Integer> all = new TreeSet<>();
        for (int d : digits) if (0 <= d && d <= 9) all.add(d);
        if (all.isEmpty()) return "-1";

        boolean hasZero = all.contains(0);
        char[] s = String.valueOf(n).toCharArray();
        int L = s.length;

        // ----- 单个数字：直接取 < limit 的最大一位（允许 0） -----
        if (L == 1) {
            int limit = s[0] - '0';
            Integer pick = all.lower(limit); // 严格小于 n
            return pick == null ? "-1" : String.valueOf((char) ('0' + pick));
        }

        // 首位不能为 0（用于构造多位数）
        TreeSet<Integer> head = new TreeSet<>(all);
        head.remove(0);

        // 如果没有非零数字可作首位，多位数构造不可能；但可以返回 0（若 0 < n）
        if (head.isEmpty()) return hasZero ? "0" : "-1";

        // 1) 先尝试和 n 同长度且 < n 的最优解
        String sameLen = tryBuildLess(all, head, s);
        if (sameLen != null) return sameLen;

        // 2) 不行就用更短一位
        int newLen = L - 1;
        if (newLen == 1) {
            // 一位数：直接取可用数字中的最大（可能为 0）
            return String.valueOf((char) ('0' + all.last()));
        } else {
            // 多位数：首位取最大非零，其余位取全局最大
            int maxAll = all.last(), maxHead = head.last();
            char[] res = new char[newLen];
            res[0] = (char) ('0' + maxHead);
            Arrays.fill(res, 1, newLen, (char) ('0' + maxAll));
            return new String(res);
        }
    }

    // 同长度构造：若能得到严格小于 n 的数，返回字符串；否则返回 null
    private static String tryBuildLess(TreeSet<Integer> all, TreeSet<Integer> head, char[] s) {
        int L = s.length;
        int[] chosen = new int[L];

        for (int i = 0; i < L; i++) {
            int limit = s[i] - '0';
            Integer pick = (i == 0 ? head : all).floor(limit);
            if (pick == null) {
                // 这一位放不下，向左借位
                if (!backoff(all, head, chosen, i - 1)) return null;
                return toString(chosen);
            }
            chosen[i] = pick;
            if (pick < limit) {
                // 已经严格小于，上界解除；后面全部填最大
                int fill = all.last();
                for (int j = i + 1; j < L; j++) chosen[j] = fill;
                return toString(chosen);
            }
        }
        // 走到这说明选出来 == n，需要从末位开始借位一次
        if (!backoff(all, head, chosen, L - 1)) return null;
        return toString(chosen);
    }

    // 从 pos 向左找能“再小一点”的位；成功则把其右侧全部填最大
    private static boolean backoff(TreeSet<Integer> all, TreeSet<Integer> head, int[] chosen, int pos) {
        for (int i = pos; i >= 0; i--) {
            Integer smaller = (i == 0 ? head : all).lower(chosen[i]);
            if (smaller != null) {
                chosen[i] = smaller;
                int fill = all.last();
                for (int j = i + 1; j < chosen.length; j++) chosen[j] = fill;
                return true;
            }
        }
        return false;
    }

    private static String toString(int[] arr) {
        StringBuilder sb = new StringBuilder(arr.length);
        for (int d : arr) sb.append((char) ('0' + d));
        return sb.toString();
    }

    // ----------- quick test -----------
    static void t(int[] digits, int n, String expect) {
        String got = maxNumBelowN(digits, n);
        System.out.printf("digits=%s, n=%d -> %s  %s%n",
                Arrays.toString(digits), n, got, expect.equals(got) ? "✔" : ("✘ expect " + expect));
    }

    public static void main(String[] args) {
        // 你原来的用例（允许返回 0 的语义）
        t(new int[]{2,3,5,8},  23121, "22888");
        t(new int[]{0,1},      1000,  "111");
        t(new int[]{0,2,3},    1000,  "333");
        t(new int[]{0},        10,    "0");   // 允许 0
        t(new int[]{5,6,7},    5,     "-1");
        t(new int[]{0,1},      0,     "-1");  // n<=0 无解

        // 补充：一位数场景
        t(new int[]{0},        1,     "0");
        t(new int[]{0,4,9},    5,     "4");
        t(new int[]{4,9},      4,     "-1");

        // 更短一位降到 1 位
        t(new int[]{0,1},      20,    "11");  // 短一位=2位 -> 11
        t(new int[]{0,1},      10,    "1");   // 短一位=1位 -> 1(=maxAll)
    }
}

```
